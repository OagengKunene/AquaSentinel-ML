# DWS/RQIS water-quality data request template

**To:** Masilela1T@dws.gov.za  
**Subject:** Request for DWS/RQIS water-quality monitoring data for research

Dear Ms Masilela,

I am developing AquaSentinel-ML, an independent research project exploring explainable statistical screening of water-quality observations. I would like to request guidance on obtaining an appropriately licensed DWS/RQIS water-quality dataset for research and validation.

I would appreciate an extract for a defined river, dam, catchment or monitoring station, preferably in CSV format. The initial study would focus on parameters such as pH, electrical conductivity, nitrate and phosphate, subject to availability and suitability.

If possible, please include the following metadata with each observation:

- Monitoring-station identifier, station name and coordinates
- Sample or activity/event identifier
- Sample date and time
- Parameter/determinant identifier and name
- Result value and original unit
- Analytical method and fraction
- Detection or quantitation limit and result qualifiers
- Laboratory/provider and any quality-assurance flags
- Dataset version, extraction date and update frequency

Could you also advise on the correct process for requesting the data, any applicable licence or conditions of use, required acknowledgement wording, and whether the extract may be used in an openly documented research software project?

I will preserve the original data and metadata, acknowledge DWS as the data proprietor as required, and will not redistribute the raw dataset or use it commercially without explicit permission.

Thank you for your time and guidance.
